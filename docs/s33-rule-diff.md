## Согласованные изменения действий и условий

Убраны вторые касания старого режима, которые после нового первого касания
сворачивали уже раскрытые списки или пытались повторно использовать закрытое
меню. Первое касание и правые края настоящих строк сохраняются. Убрано
ветвление по `one`: проверки сворачивания без навигации, восстановления
открытого списка и закрытия главы выполняются во всех семи вариантах, с теми
же выражениями assertions и геометрическими порогами.

Добавлены только снимки длины истории перед соответствующими действиями.
Проверки запроса поиска, перехода по результату, одной записи истории и
отсутствия ошибок страницы сохранены. Поведение приложения, поиск слов,
видимость результата и размеры строк этой правкой не меняются.

Ранее для выполнения задания на двух телефонах в s33 зарегистрирован Pixel 7;
для точного отчёта об ошибках добавлен traceback. Эти изменения не отменяют
проверок. [Полный diff](pr2-evidence/s33-rule-diff.patch) содержит всю правку.
