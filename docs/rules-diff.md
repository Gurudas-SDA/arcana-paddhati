# Правила интерфейса книг: дополнение к §9

Формулировка для внесения Липикарой в «Правила интерфейса книг» в день слияния
заявки, согласно исходному заданию §6 и дополнению №1 §Е. Правило 9.12 не
изменяется; поведение восстановления списка через «Назад» этой заявкой не
меняется.

**9.13.** Касание строки главы в «Содержании» оставляет эту строку видимой:
список прокручивается так, чтобы строка главы и первая строка её подразделов
были видны целиком. Строка главы не уходит ни выше верхнего, ни ниже нижнего
края видимой части списка.
